# Morita S TP Comparison v2

This module compares TP100, TP125, and fixed 50/50 staged exit using only the synthetic fixed-IV reference model output.

Target touches use daily high marks and fill exactly at the threshold. Independent terminal exits use daily close marks. It does not claim actual intraday ordering, listed option availability, or broker fill quality.

The report is descriptive under frozen reference-model assumptions only. It does not change live Morita Bot alerts, targets, stops, sizing, or execution.
