# Vol-Control Cross-Spec Characterization v1

This characterization is historical descriptive state-path research only.

It requires exactly six predeclared transparent vol-control artifacts for the NDX exact descriptive input:

- `vc_daily_20d_target10_cap100_v1`
- `vc_daily_40d_target10_cap100_v1`
- `vc_daily_60d_target10_cap100_v1`
- `vc_daily_20d_target12_cap100_v1`
- `vc_daily_40d_target12_cap100_v1`
- `vc_daily_60d_target12_cap100_v1`

The analysis reports exposure-path summaries and pairwise exposure dispersion across the fixed windows: full covered period, pre-2025, from-2025, calendar 2024, calendar 2025, calendar 2023 H2, and calendar 2026 YTD.

There is no external manager-flow ground truth in this characterization. It does not calculate returns, PnL, Sharpe, alpha, performance correlation, ranking, winner, pass/fail, model selection, strict PIT eligibility, Phase 2 admission, trading signal, sizing, notification, or execution.
