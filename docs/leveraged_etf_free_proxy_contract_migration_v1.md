# Leveraged ETF Free Proxy Contract Migration v1

## Decision

The active manual input contract is the normalized five-file layout generated by:

```powershell
python market_bomb_leveraged_etf_free_proxy_v1.py build-leveraged-etf-free-proxy-template --input-id <opaque_input_id>
```

Legacy per-ticker names are not supported active input filenames. Use the normalized template generated by `build-leveraged-etf-free-proxy-template`.

## Canonical Replacement

| Deprecated planning name | Canonical normalized destination |
|---|---|
| `ndx_daily.csv` | `sources/benchmark_prices.csv` with `instrument=NDX` |
| `qqq_daily.csv` | `sources/benchmark_prices.csv` with `instrument=QQQ` |
| `tqqq_daily.csv` | `sources/leveraged_etf_prices.csv` with `instrument=TQQQ` |
| `sqqq_daily.csv` | `sources/leveraged_etf_prices.csv` with `instrument=SQQQ` |

| `sqqq_aum_nav.csv` | `sources/aum_or_capital.csv` with `instrument=SQQQ` |
| `tqqq_splits.csv` | `sources/split_history.csv` with `instrument=TQQQ` |
| `sqqq_splits.csv` | `sources/split_history.csv` with `instrument=SQQQ` |

## Mapping Correction

For NDX exact mode:

```text
TQQQ -> NDX, market proxy QQQ, target_leverage=+3, directionality=long, benchmark_exact_or_proxy=benchmark_exact
SQQQ -> NDX, market proxy QQQ, target_leverage=-3, directionality=inverse, benchmark_exact_or_proxy=benchmark_exact
```

`TQQQ -> QQQ` and `SQQQ -> QQQ` are not valid exact mappings. QQQ is proxy-only unless the run explicitly uses `qqq_proxy_only_descriptive`.

## Operator Migration

1. Build a fresh template.
2. Move manually acquired source extracts into the normalized CSVs.
3. Complete one manifest entry per normalized file.
4. Inspect the package with `inspect-leveraged-etf-free-proxy-input-contract`.
5. Validate with `validate-leveraged-etf-free-proxy-input`.
6. Run only descriptive mode after validation.

Do not add compatibility aliases for deprecated filenames unless a real production dependency is identified and approved.
