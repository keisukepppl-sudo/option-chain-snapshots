# Morita S Risk Profile v1

Daily-OHLCV-only descriptive risk characterization for the existing formal Morita Bot S-rank breakout baseline.

This module reuses the verified formal baseline, the baseline `source_input_lineage.json`, and the baseline fields `entry_price`, `entry_session`, `breakout_day_low`, and `outcome_observed_through_session`. It does not rebuild the Bot, change rules, optimize stops, model options, or create alerts.

Outputs are local research artifacts under `outputs/morita_s_risk_profile/`.
