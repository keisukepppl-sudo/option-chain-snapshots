# Morita S1/PB/C Route Boundary v0.1

Boundary:

- Research calendar construction only.
- No production notification, Pushover, persistent state ledger, broker access, order instruction, portfolio return, portfolio drawdown replay, or sizing research.
- No raw S/A/B definition change.
- No old vertical P&L or PF4 reconstruction.
- No parameter sweep and no profit-factor targeting.

Cluster proxy is not a verified chart base. A raw S after a gap greater than 20 eligible sessions starts a new proxy cluster for research comparison only. It is not a confirmed new base or live re-entry rule.

PB is not an actionable pullback entry in this module. Low-volume, base-validity, and rebound-confirmation flags remain a later refinement task.

C is a continuation-selection sample. Its existence depends on a later raw S event already occurring, so C results must not be read as permission to buy every high update.
